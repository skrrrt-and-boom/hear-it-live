# Composition matching

- Prefer composer plus a catalogue identifier (BWV, K./KV, Hob., D., RV, Op. with work number). The same Op. number can occur under different composers. A catalogue substring is not an exact match: BWV 54 is not BWV 544.
- A source's catalogue number must refer to the performed work, not an artist biography or a different event on the same page. Read the relevant programme section.
- Normalise accents, translations and punctuation only when the identity is clear. A translated title alone can remain ambiguous; use composer, instrumentation, key and catalogue together.
- An individual movement in a playlist is satisfied by an explicitly announced performance of that movement or the complete containing work, with the relationship explained. An excerpt does not satisfy a request for the whole work. Do not infer inclusion when cuts or selections are announced.
- An arrangement is an arrangement, even if a catalogue number identifies its source. Include only when the user accepts arrangements. A different recording performer can play the same work.
- If the user opts into composer mode, show it as a composer match, not an exact-work match. In nearby mode, report discovery relevance without implying requested repertoire.
- A publication that names only “Bach” cannot verify a specific Bach work. No programme, unknown movement, conflicting number, unidentified arrangement or ambiguous composer stays a lead until resolved.
- Distinguish a concert, a recital embedded in worship and an ordinary service. Include the latter two only under the user's chosen scope.

Record what the source actually establishes. Match judgements remain the assistant's responsibility; the report tool validates structure and consistency, not musical identity or the truth of a website.
