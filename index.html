How it works

Install the free concert-finder skill, then paste the prepared request into Codex or Claude Code with web research tools. Your assistant reuses a complete saved playlist, then finds performances with original announcements. Computer use is prohibited in the concert-search workflow. A new playlist may need a separate one-time import.

This page stores nothing and sends no playlist data. Saved playlists are dated snapshots. Direct Spotify page fetching can expose only a preview; the skill must report that gap rather than launch browser automation. Spotify access and content-use conditions still apply; this is not a Spotify-approved integration. Your assistant’s plan and usage limits apply.
